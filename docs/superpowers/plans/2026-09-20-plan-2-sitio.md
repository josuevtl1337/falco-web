# Plan 2 — El sitio público

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que `falco.cafe` exista de verdad: cinco pantallas servidas desde Cloudflare Workers con los datos reales de D1, y un pedido que se arma en el navegador y termina en un mensaje de WhatsApp que Falco tiene que confirmar.

**Architecture:** Una app Astro (`apps/site`) con SSR en Workers, **todas las rutas dinámicas** (sin prerender). Lee D1 a través de una capa de consultas de solo lectura en `packages/db`, que devuelve tipos de fila en `camelCase`. El HTML sale armado del servidor; solo hay dos islas de React: el estado "Abierto ahora" (se recalcula cada minuto) y el pedido (vive en `localStorage`). Toda la lógica de negocio ya está en `@falco/domain` y no se reescribe.

**Tech Stack:** Astro 7.3.3, @astrojs/cloudflare 14.3.2, @astrojs/react 6.0.6, React 19, wrangler 4.135, Cloudflare D1, CSS propio con custom properties de `@falco/ui`, Fontsource para las tipografías OFL, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-18-falco-web-design.md`
**Arrastre del Plan 1 (leer antes de empezar):** `docs/superpowers/notes/2026-09-20-arrastre-del-plan-1.md`
**Wireframes de referencia:** `design/persona/wireframes.html` (v7.9) — se abren con `python3 -m http.server 4173 --directory design`

## Global Constraints

- Textos que ve el usuario en **español rioplatense**; código, nombres de archivo, tablas, columnas y rutas en **inglés**. Los nombres de `describe`/`it` de los tests van en español.
- Todas las horas se interpretan en `America/Argentina/Buenos_Aires`, **nunca** con la hora del dispositivo.
- Precios en pesos enteros. El total del pedido siempre se llama **"Total estimado"**.
- Pedido: máximo **20 productos distintos** y **2 unidades por producto**, contadas por producto (sumando sus variantes). La API es `ORDER_LIMITS = { maxProducts, maxUnitsPerProduct }` y `AddOutcome.product_limit`.
- Palabras fijas del pedido: **"confirmar"** y **"no está reservado"**. Nunca "comprado", "listo" ni "pedido hecho" antes de la respuesta de Falco.
- Clave de guardado: `falco.order.v1`. Código de pedido: `F-XXXX`. Vencimiento: 3 días sin enviar, 48 horas enviado.
- Mensaje de WhatsApp: empieza con `¡Buenas!`, dice "Total estimado", y termina con `¿Me confirman si hay stock y desde qué hora lo puedo retirar?`.
- Paleta (tokens de `@falco/ui`): carbón `#292A2C`, piedra `#313335`, sombra `#1E1F21`, tostado `#885333`, hueso `#E8E2D0`, ceniza `#9A9C9E`, brasa `#F2C48B`. Sin rojo.
  > Pendiente del dueño: los colores exactos del logo vectorial son `#2A2A2C`, `#985D36` y `#ECE4CF`. Si decide alinearlos, es **un solo commit** sobre `tokens.ts`, `tokens.css` y su test. No bloquea ninguna tarea.
- Ángulos fijos: placas −14°, botones −12°, menú −8°, caja de diálogo −6°, ticker −1,6°.
- Todo lo que se toca mide al menos **44 px**. Contraste mínimo AA.
- Con `prefers-reduced-motion`: sin franjas, sin rebotes y sin carrusel automático.
- El Worker del sitio es de **solo lectura**: solo `SELECT`, ninguna ruta que escriba.
- TypeScript **6.0.3**, estricto, con `noUncheckedIndexedAccess`. Node ≥ 22.12 (lo exige Astro 7).
  > Corregido al ejecutar la Tarea 1: el repo estaba en TypeScript 7.0.2 y **`astro check` lo rechaza**
  > (el compilador nativo todavía no expone la API que necesita el language server). Se bajó a 6.0.3 para
  > poder chequear el frontmatter de los `.astro`. A diferencia de TS 7, la 6 **no** hardcodea
  > `esModuleInterop`: si algún paquete lo necesita, se agrega a su tsconfig y se explica por qué.
- **zod 3** (`^3.25.76`, ya instalado). No migrar a zod 4 en este plan: cambia la API de mensajes de error y reescribiría `schemas.ts`.
- Commits convencionales, **sin ninguna línea de atribución de IA**.

### Dos trampas verificadas el 2026-09-20 (no descubrirlas de nuevo a mano)

1. **`Astro.locals.runtime` ya no existe.** Fue eliminado en `@astrojs/cloudflare` v14. Los bindings se leen con `import { env } from "cloudflare:workers"`.
2. **El import `cloudflare:workers` rompe el build si hay rutas prerenderizadas.** Por eso el sitio va con `output: "server"` y **ninguna** ruta usa `prerender = true` ni `getStaticPaths`. Si una tarea necesita una página estática, no la hace estática: la sirve desde el servidor y la cachea en el borde (Tarea 9).

```ts
  body: number;
  aroma: number;
  finish: number;
};

export type ProductRow = {
  id: number;
  slug: string;
  kind: string;
  shelf: string;
  coffee_id: number | null;
  name: string;
  detail: string;
  description: string | null;
  price_ars: number;
  image_key: string | null;
  is_new: number;
  is_visible: number;
  ask_stock: number;
  sort_order: number;
};

export type ProductOptionRow = {
  id: number;
  product_id: number;
  label: string;
  is_available: number;
  sort_order: number;
};

export type TastingProfile = {
  acidity: number;
  sweetness: number;
  body: number;
  aroma: number;
  finish: number;
};

export type Coffee = {
  id: number;
  name: string;
  farm?: string;
  country: string;
  variety?: string;
  process?: string;
  altitudeMasl?: number;
  tastingNotes?: string;
  description?: string;
  roaster: string;
  profile: TastingProfile;
};

export type ProductOption = {
  id: number;
  label: string;
  isAvailable: boolean;
  sortOrder: number;
};

export type Product = {
  id: number;
  slug: string;
  kind: "coffee" | "gear" | "kit" | "apparel";
  shelf: "coffee" | "kits";
  coffeeId?: number;
  name: string;
  detail: string;
  description?: string;
  priceArs: number;
  imageKey?: string;
  isNew: boolean;
  isVisible: boolean;
  askStock: boolean;
  sortOrder: number;
};

export type ProductWithOptions = Product & { options: ProductOption[] };

// SQLite guarda los booleanos como 0 y 1, y las columnas vacías como NULL.
// El resto del código habla en booleanos y en undefined.
const bool = (value: number): boolean => value === 1;
const maybe = <T>(value: T | null): T | undefined => value ?? undefined;

export function toCoffee(row: CoffeeRow): Coffee {
  return {
    id: row.id,
    name: row.name,
    farm: maybe(row.farm),
    country: row.country,
    variety: maybe(row.variety),
    process: maybe(row.process),
    altitudeMasl: maybe(row.altitude_masl),
    tastingNotes: maybe(row.tasting_notes),
    description: maybe(row.description),
    roaster: row.roaster,
    profile: {
      acidity: row.acidity,
      sweetness: row.sweetness,
      body: row.body,
      aroma: row.aroma,
      finish: row.finish,
    },
  };
}

export function toProduct(row: ProductRow): Product {
  return {
    id: row.id,
    slug: row.slug,
    kind: row.kind as Product["kind"],
    shelf: row.shelf as Product["shelf"],
    coffeeId: maybe(row.coffee_id),
    name: row.name,
    detail: row.detail,
    description: maybe(row.description),
    priceArs: row.price_ars,
    imageKey: maybe(row.image_key),
    isNew: bool(row.is_new),
    isVisible: bool(row.is_visible),
    askStock: bool(row.ask_stock),
    sortOrder: row.sort_order,
  };
}

export function toProductOption(row: ProductOptionRow): ProductOption {
  return {
    id: row.id,
    label: row.label,
    isAvailable: bool(row.is_available),
    sortOrder: row.sort_order,
  };
}
```

```ts
// El mínimo que comparten D1 y better-sqlite3, para poder probar las consultas
// sin levantar un Worker. D1 devuelve promesas; better-sqlite3, valores sueltos.
export type PreparedLike = {
  bind(...values: unknown[]): PreparedLike;
  first<T>(): Promise<T | null> | T | undefined;
  all<T>(): Promise<{ results: T[] }> | T[];
};

export type ReadableDb = { prepare(sql: string): PreparedLike };

async function firstRow<T>(statement: PreparedLike): Promise<T | undefined> {
  const value = await statement.first<T>();
  return value ?? undefined;
}

async function allRows<T>(statement: PreparedLike): Promise<T[]> {
  const value = await statement.all<T>();
  return Array.isArray(value) ? value : value.results;
}

export type SettingsMap = Partial<Record<string, string>>;

export async function getSettings(db: ReadableDb): Promise<SettingsMap> {
  const rows = await allRows<{ key: string; value: string }>(
    db.prepare("SELECT key, value FROM settings"),
  );
  const settings: SettingsMap = {};
  for (const row of rows) settings[row.key] = row.value;
  return settings;
}

export async function getHopperCoffee(
  db: ReadableDb,
): Promise<Coffee | undefined> {
  const setting = await firstRow<{ value: string }>(
    db.prepare("SELECT value FROM settings WHERE key = 'hopper_coffee_id'"),
  );
  if (!setting) return undefined;
  const id = Number(setting.value);
  if (!Number.isInteger(id)) return undefined;
  const row = await firstRow<CoffeeRow>(
    db.prepare("SELECT * FROM coffees WHERE id = ?").bind(id),
  );
  return row ? toCoffee(row) : undefined;
}

async function withOptions(
  db: ReadableDb,
  rows: ProductRow[],
): Promise<ProductWithOptions[]> {
  if (rows.length === 0) return [];
  const options = await allRows<ProductOptionRow>(
    db
      .prepare(
        "SELECT * FROM product_options WHERE product_id IN (" +
          rows.map(() => "?").join(", ") +
          ") ORDER BY sort_order",
      )
      .bind(...rows.map((row) => row.id)),
  );
  return rows.map((row) => ({
    ...toProduct(row),
    options: options
      .filter((option) => option.product_id === row.id)
      .map(toProductOption),
  }));
}

export async function listShelf(
  db: ReadableDb,
  shelf: "coffee" | "kits",
): Promise<ProductWithOptions[]> {
  const rows = await allRows<ProductRow>(
    db
      .prepare(
        "SELECT * FROM products WHERE shelf = ? AND is_visible = 1 ORDER BY sort_order, id",
      )
      .bind(shelf),
  );
  return withOptions(db, rows);
}

export async function getProductBySlug(
  db: ReadableDb,
  slug: string,
): Promise<ProductWithOptions | undefined> {
  const row = await firstRow<ProductRow>(
    db
      .prepare("SELECT * FROM products WHERE slug = ? AND is_visible = 1")
      .bind(slug),
  );
  if (!row) return undefined;
  const [product] = await withOptions(db, [row]);
  return product;
}

export async function getWeekHours(db: ReadableDb): Promise<WeekHours> {
  const rows = await allRows<{
    weekday: number;
    is_closed: number;
    opens_at: string | null;
    closes_at: string | null;
  }>(db.prepare("SELECT * FROM business_hours ORDER BY weekday"));
  // WeekHours es Readonly<Record<number, DayHours>>: se arma un objeto mutable
  // y recién al devolverlo toma el tipo de solo lectura.
  const week: Record<number, DayHours> = {};
  for (const row of rows) {
    week[row.weekday] = {
      isClosed: row.is_closed === 1,
      opensAt: row.opens_at,
      closesAt: row.closes_at,
    };
  }
  return week;
}

export async function getUpcomingSpecialDays(
  db: ReadableDb,
  fromDate: string,
  days: number,
): Promise<
  {
    date: string;
    isClosed: boolean;
    opensAt: string | null;
    closesAt: string | null;
    note?: string;
  }[]
> {
  const rows = await allRows<{
    date: string;
    is_closed: number;
    opens_at: string | null;
    closes_at: string | null;
    note: string | null;
  }>(
    db
      .prepare(
        "SELECT * FROM special_days WHERE date >= ? ORDER BY date LIMIT ?",
      )
      .bind(fromDate, days),
  );
  return rows.map((row) => ({
    date: row.date,
    isClosed: row.is_closed === 1,
    opensAt: row.opens_at,
    closesAt: row.closes_at,
    note: row.note ?? undefined,
  }));
}
```

```tsx
import { useEffect, useState } from "react";
import {
  getOpenStatus,
  type OpenStatus,
  type SpecialDay,
  type WeekHours,
} from "@falco/domain";

type Props = {
  week: WeekHours;
  specials: SpecialDay[];
  /** El estado ya calculado en el servidor: la primera pintura no espera al JS. */
  initial: OpenStatus;
};

export function OpenNow({ week, specials, initial }: Props) {
  // getOpenStatus devuelve un objeto { state, label, … }, no un texto suelto:
  // el estado sale de `state`, nunca de leer el texto con startsWith.
  const [status, setStatus] = useState<OpenStatus>(initial);

  useEffect(() => {
    const recalculate = () =>
      setStatus(getOpenStatus(new Date(), week, specials));
    recalculate();
    const timer = setInterval(recalculate, 60_000);
    return () => clearInterval(timer);
  }, [week, specials]);

  return (
    <p
      role="status"
      data-open={status.state === "open"}
      className="abierto-ahora"
    >
      <span className="punto" aria-hidden="true" />
      {status.label}
    </p>
  );
}
```

```ts
export const PENTAGON_AXES = [
  "acidity",
  "sweetness",
  "body",
  "aroma",
  "finish",

export const PENTAGON_LABELS: Record<keyof TastingProfile, string> = {
  acidity: "Acidez",
  sweetness: "Dulzor",
  body: "Cuerpo",
  aroma: "Aroma",
  finish: "Final",

// Lienzo de 100 × 100, centro en (50, 50), radio máximo 40.
// El primer eje arranca arriba y los demás giran en sentido horario.
export function pentagonPoints(
  profile: TastingProfile,
): { x: number; y: number }[] {
  return PENTAGON_AXES.map((axis, index) => {
    const angle = -Math.PI / 2 + (index * 2 * Math.PI) / PENTAGON_AXES.length;
    const radius = (profile[axis] / 5) * 40;
    return {
      x: 50 + radius * Math.cos(angle),
      y: 50 + radius * Math.sin(angle),
    };
  });
}
```

```ts
import {
  clearOrder,
  loadOrder,
  pruneUnavailable,
  saveOrder,
  type Catalog,
  type KeyValueStorage,
  type Order,
  type OrderLine,
} from "@falco/domain";

export type SiteCatalog = Catalog;

export type LoadResult = {
  order: Order | undefined;
  /** Las líneas que se sacaron porque el producto o la opción ya no están. */
  removed: OrderLine[];
};

function isStillAvailable(line: OrderLine, catalog: SiteCatalog): boolean {
  const product = catalog.get(line.productId);
  if (!product) return false;
  if (line.optionId === undefined) return true;
  return Boolean(
    product.options?.some((option) => option.id === line.optionId),
  );
}

/**
 * Carga el pedido guardado y le saca lo que ya no se puede pedir.
 * Devuelve qué sacó: la persona tiene que enterarse, porque el mensaje de
 * WhatsApp descarta esas líneas en silencio.
 */
export function loadPrunedOrder(
  storage: KeyValueStorage,
  catalog: SiteCatalog,
  now: Date = new Date(),
): LoadResult {
  const stored = loadOrder(storage, now);
  if (!stored) return { order: undefined, removed: [] };

  const pruned = pruneUnavailable(
    stored,
    (line) => isStillAvailable(line, catalog),
    now,
  );
  const removed = stored.items.filter(
    (line) =>
      !pruned.items.some(
        (kept) =>
          kept.productId === line.productId && kept.optionId === line.optionId,
      ),
  );
  if (removed.length > 0) saveOrder(storage, pruned);
  return { order: pruned, removed };
}

export function resetOrder(storage: KeyValueStorage): void {
  clearOrder(storage);
}
```

```tsx
import { useState } from "react";
import {
  ORDER_LIMITS,
  addItem,

} from "@falco/domain";

type Props = {
  productId: number;
  productName: string;
  options: { id: number; label: string; isAvailable: boolean }[];
};

export function AddToOrder({ productId, productName, options }: Props) {
  const available = options.filter((option) => option.isAvailable);
  const [optionId, setOptionId] = useState<number | undefined>(
    available[0]?.id,
  );
  const [notice, setNotice] = useState<string | undefined>();

  function add() {
    const now = new Date();
    const current: Order =
      loadOrder(localStorage, now) ?? createOrder(generateOrderCode(), now);

    saveOrder(localStorage, result.order);

      setNotice(

      );
    else if (result.outcome === "product_limit")
      setNotice(
        `El pedido llega hasta ${ORDER_LIMITS.maxProducts} productos distintos. Mandá este y después armás otro.`,
      );
    else setNotice("Lo sumamos al pedido. Todavía no está reservado.");
  }

  return (
    <div className="sumar">
      {available.length > 0 && (
        <fieldset>
          <legend>Elegí una opción</legend>
          {available.map((option) => (
            <label key={option.id}>
              <input
                type="radio"
                name={`opcion-${productId}`}
                checked={optionId === option.id}
                onChange={() => setOptionId(option.id)}
              />
              {option.label}
            </label>
          ))}
        </fieldset>
      )}
      <button type="button" className="boton" onClick={add}>
        Sumar al pedido
      </button>
      {notice && <p role="status">{notice}</p>}

  );
}
```

```ts
import type { APIRoute } from "astro";
import { env } from "cloudflare:workers";
import { getSettings } from "@falco/db";

/**
 * 302 y no 301: un 301 queda guardado en el navegador de quien escaneó el QR,
 * y si después cambia el link de Drive esa persona seguiría yendo al viejo.
 */
export function cartaRedirect(menuUrl: string | undefined): Response {
  if (!menuUrl || !menuUrl.startsWith("https://")) {
    return new Response("Todavía no cargamos la carta.", {
      status: 404,
      headers: { "cache-control": "no-store" },
    });
  }
  return new Response(null, {
    status: 302,
    headers: { location: menuUrl, "cache-control": "no-store" },
  });
}

export const GET: APIRoute = async () => {
  const settings = await getSettings(env.DB);
  return cartaRedirect(settings.menu_url);
};
```

```ts
import type { MiddlewareHandler } from "astro";

const NO_STORE = new Set(["/carta", "/404"]);

/**
 * max-age=0 para el navegador y s-maxage=60 para el borde: la persona siempre
 * revalida, pero Cloudflare responde sin pegarle a D1 durante un minuto.
 */
export function cacheHeaderFor(pathname: string): string {
  return NO_STORE.has(pathname) ? "no-store" : "public, max-age=0, s-maxage=60";
}

export const onRequest: MiddlewareHandler = async (context, next) => {
  const response = await next();
  const type = response.headers.get("content-type") ?? "";
  if (type.includes("text/html")) {
    response.headers.set("cache-control", cacheHeaderFor(context.url.pathname));
  }
  return response;
};
```
